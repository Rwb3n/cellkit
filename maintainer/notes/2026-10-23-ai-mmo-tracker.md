# AI-MMO's GitHub tracker, as it runs (2026-10-23)

Read-only survey of Rwb3n/scally (143 issues, board "Scally" #6, the repo's docs and git log), for the cellkit tracker the operator asked for ("manage work via gh in a way inspired by AI-MMO").

## Two eras

- **#1–#108 (4 and 8 Oct): generated** by `tools/workbuild/workbuild.py issues gate<N>.json`. Each got a gate milestone, `cell:` and `track:` labels, a board item and every field (Gate, Cell, Priority, Module, Requirements, Track). Bodies short, with a generated footer.
- **#109–#143 (37 issues): filed by hand.** Labels kept up (142/143 a `cell:` label, 143/143 `track:`). **None has a milestone or is on the board.** Bodies longer, in prose: provenance ("Operator agreed (session 10)", decision and assumption ids), scope, expected output ("a negative result is a result", #142), ordering ("after #129"), "Refs #…".

## What held up

- Labels (`cell:<name>`, `track:product|system|instrument`).
- Closing by landing: 93 of 108 closed issues by `Closes #N` in the land's merge message. The other 15, exactly the no-code ones (touches, playtests, spikes), closed by hand with an outcome comment.
- Issue comments as durable memory for cell replies and reports (#142 the spike report, #143 "later" findings).
- A rolling agenda issue (#128) with the operator's reprioritisations, and a "Now" list in the root's handbook: the real priority queue. Approval itself stays in the charter log, not GitHub.

## What decayed

- The board: 107 items, all generated; Status never "In Progress"; #34 closed but Todo; the last two weeks of work missing.
- Priority: 88 of 106 `must`.
- Single-select fields whose options grow: `gym` never added as a Cell option.
- Written rules out of date: "issues are generated by tools/workbuild"; "pick work from the board"; title prefixes beyond the gate-1 set undocumented.

## Taken for cellkit (Roadmap #52)

`area:` labels; milestones as releases, set at Next; the board with Status only, every issue added by one command (`maintainer/tools/file.ts`); a pinned Roadmap issue for direction and the operator's priority calls; the body anatomy (Outcome, After, Refs, Source); close by `Fixes #n`, or by hand with an outcome. Left out: gates, Priority/Module/Requirements fields, title prefixes, generating issues from data files.

Not checked: the board's views and built-in workflows (the CLI can't read them); who acted (one account for everything).
